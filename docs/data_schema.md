# 排期数据字段定义

## 字段列表

| 字段名             | 类型    | 必填 | 说明                                                 | 示例值                           |
| ------------------ | ------- | ---- | ---------------------------------------------------- | -------------------------------- |
| `item_id`          | string  | ✅    | 唯一标识，5位数字，时装以0开头，随身物品以1开头      | `"00001"`                        |
| `name`             | string  | ✅    | 物品名称                                             | `"绯"`                           |
| `type`             | enum    | ✅    | 物品类型：`时装` / `随身物品`                        | `"时装"`                         |
| `quality`          | enum    | ✅    | 品质：`稀世` / `奇珍`（当前仅统计这两类）            | `"奇珍"`                         |
| `role`             | string  | ✅    | 所属角色名                                           | `"祭司"`                         |
| `release_date`     | string  | ✅    | 上架日期，格式 YYYY-MM-DD                            | `"2023-12-04"`                   |
| `price_effective`  | number  | ❌    | 实际最低获取价（数值部分）                           | `699`                            |
| `price_currency`   | string  | ❌    | 货币单位：`人民币` / `回声` / `碎片` / `灵感` / `无` | `"人民币"`                       |
| `price_reference`  | number  | ❌    | 参考价值（用于排期指数权重计算）                     | `24000`                          |
| `is_limited`       | boolean | ✅    | 是否限定（绝版）                                     | `true`                           |
| `is_time_limited`  | boolean | ✅    | 是否限时上架                                         | `false`                          |
| `is_collaboration` | boolean | ✅    | 是否联动IP                                           | `false`                          |
| `is_paid`          | boolean | ✅    | 是否必须付费获取（不包含可免费囤积的抽取类）         | `true`                           |
| `tags`             | array   | ❌    | 额外标签数组                                         | `["真理之下限时礼盒"]`           |
| `skip_in_analysis` | boolean | ❌    | 是否在排期分析中跳过（用于升级挂件的低版本等）       | `true`                           |
| `skip_reason`      | string  | ❌    | 跳过原因说明                                         | `"紫升金升级过渡品，不计入排期"` |

## 枚举值规范

### type
- `时装`
- `随身物品`

### quality（当前统计范围）
- `稀世`（金皮）
- `奇珍`（紫皮）
> 注：`独特`（蓝皮）暂不纳入统计，预留扩展空间。

### price_currency
- `人民币`：实体周边/CDK类
- `回声`：游戏充值货币
- `碎片`：游戏内免费货币
- `灵感`：精华抽取专用
- `无`：活动赠送等无成本物品

## 特殊规则

### 可升级联动挂件（紫→金）
仅计入最高品质版本（金挂），低版本设置 `skip_in_analysis: true`。

### P5联动可切换皮肤（如明智吾郎/CROW）
视为两件独立时装，分别计入，通过 `name` 字段区分。

### 精华金皮
`is_paid: false`，但 `price_reference` 填入保底成本折算值（如 250抽 × 96灵感/抽 ÷ 10 = 2400回声）。
